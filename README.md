# For Riya — My Story

An interactive, scroll-based story website about my journey — from an ITI student,
to machines, to computers, to code, to 3D... and the idea of Riya.

## Run locally

Any static file server works. For example:

```bash
python3 -m http.server 8300
```

Then open http://localhost:8300 and click **let's start**.

> Tip: the experience uses sound effects. Click "let's start" first so the browser
> unlocks audio, then scroll slowly through the story.
